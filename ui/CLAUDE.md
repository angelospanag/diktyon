# UI — Diktyon Next.js app

> **Note**: This is Next.js 16. Before writing any code, read the relevant guide in `node_modules/next/dist/docs/`. Key change from prior versions: Middleware is now named **Proxy** (`proxy.ts` instead of `middleware.ts`).

Next.js 16 App Router SPA. Renders the corporate network graph as an interactive corkboard — HTML polaroid cards, SVG red-thread edges, d3-force layout.

## Stack

| Concern | Library |
|---|---|
| Build | Next.js 16 (Turbopack) + TypeScript 5 |
| UI framework | React 19 |
| Styling | Tailwind CSS v4 |
| Routing | App Router — `useSearchParams` + `useRouter` from `next/navigation` |
| Data fetching | TanStack Query v5 |
| Graph layout | `d3-force` v3 (synchronous, 300 ticks before render) |
| API client | `@hey-api/client-next` + generated `client/` from `api/openapi.yaml` |
| Package manager | **bun** — do not use npm or yarn |

## Brand tokens

Defined in `app/globals.css` `:root`. Always use these — don't hardcode hex values.

| Token | Value | Use |
|---|---|---|
| `--color-cork` | `#b8803a` | Cork board base |
| `--color-manila` | `#faf6f0` | Card background / page tint |
| `--color-navy` | `#1a1a2e` | Primary text |
| `--color-string` | `#cc2200` | Red string edges, accents, CTA buttons |

The `.cork-board` utility class in `globals.css` applies the SVG fractal-noise + layered radial-gradient cork texture.

## GraphCanvas architecture

`GraphCanvas` is a `forwardRef` component exposing four imperative methods:

```ts
setGraph(graph: GraphResponse)      // replace entire graph; runs layout then fits viewport
addGraph(graph: GraphResponse)      // merge new nodes/edges; pins existing nodes during re-layout
fit()                               // fit all nodes into the visible viewport
setHoveredNode(id: string | null)   // highlight a node from outside the canvas (e.g. GraphRoster)
```

**Layout**: `runLayout()` runs a d3-force simulation synchronously (300 ticks) before any render — no visible jitter. Company nodes repel at −1800 strength; officers/PSCs repel softly at −400. Links to company nodes use distance 160; officer↔officer links use 240.

**Rendering**: Pure HTML + SVG — no canvas or WebGL.
- `.cork-board` class provides the texture background.
- A scene `div` at the container centre carries `transform: translate(pan) scale(zoom)` with `transformOrigin: 0 0`.
- `PolaroidCard`: absolutely positioned at `(node.x, node.y)`, centred with `translate(-50%, -50%)`, tilted via `tiltAngle(node.id)` — a stable hash of the node ID. Includes an SVG pushpin and a `photo-develop` CSS animation on mount.
- `StringEdge`: SVG `<path>` quadratic bezier with a sag; `textPath` label (officer role/"controls"); always drawn left-to-right so text reads correctly.
- Pan: `mousedown`/`mousemove` on the container.
- Zoom: `wheel` listener with `passive: false` and mouse-centred zoom math.
- Node drag: `onMouseDown` on each card sets `draggingNodeId`; `onMouseMove` translates to scene coordinates and updates position in both state and the backing ref (so edges track in real-time).

## API proxy

`app/api/[...path]/route.ts` is a Route Handler that forwards all `/api/*` requests to the Go backend. It reads `API_URL` at request time, so the container image stays environment-agnostic.

| Context | Setting |
|---|---|
| Dev | Default: proxies to `http://localhost:8080` |
| Podman Compose | Set `API_URL=http://backend:8080` in the service environment |
| Production | Set `API_URL=https://your-api-host` |

`API_URL` is a server-side env var (no `NEXT_PUBLIC_` prefix). The browser always uses relative `/api/*` paths.

## Dev

```bash
cd ui

```

The Go API must be running on `:8080`.

## Adding a new node type

1. Add the type to `NodeType` in `types/api.ts`.
2. Add entries to `NODE_BG`, `NODE_BORDER`, `BADGE_COLOR`, `PIN_COLOR` in `components/GraphCanvas.tsx`.
3. Add any new metadata fields to `NodeMeta` in `types/api.ts`.
4. Display them in `components/NodePanel.tsx`.
5. Add the type's border colour to `SECTION_BORDER` in `components/GraphRoster.tsx`.
