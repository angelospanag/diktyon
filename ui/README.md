# Diktyon — UI

Next.js 16 frontend for Diktyon. Renders UK corporate network graphs as an interactive corkboard — polaroid cards, red-thread edges, cork texture.

## Features

- d3-force graph layout (300 synchronous ticks — no visible jitter on load)
- Polaroid card nodes with stable per-entity rotation
- SVG quadratic-bezier red-thread edges with role labels
- Slide-out detail panel for the selected node
- Entity roster with hover-to-highlight sync to the canvas
- Autocomplete company search

## Tech Stack

Next.js 16 • React 19 • TypeScript 5 • Tailwind CSS v4 • d3-force v3 • TanStack Query v5 • hey-api • bun

## Getting Started

Requires [bun](https://bun.sh/) and the Go API running on `:8080` (see `../api`).

```bash
# macOS / Linux
curl https://mise.run | sh

# Windows
winget install jdx.mise
```

Activate mise in your shell (`~/.zshrc`):

```zsh
eval "$(mise activate zsh)"
```

Then:

```bash
mise trust
mise install      # pins Bun version from mise.toml
mise run install  # bun install
mise run dev      # http://localhost:3000
```

UI: **http://localhost:3000**

## Development

| Command              | Description                                     |
| -------------------- | ----------------------------------------------- |
| `mise run install`   | Install dependencies (first time only)          |
| `mise run dev`       | Next.js dev server on :3000                     |
| `mise run build`     | Production build (standalone output)            |
| `mise run typecheck` | TypeScript check                                |
| `mise run fmt`       | Format code (Biome)                             |
| `mise run lint`      | Lint code (Biome)                               |
| `mise run generate`  | Regenerate `client/` from `../api/openapi.yaml` |

## Configuration

```bash
API_URL="http://localhost:8080"   # Go backend address (server-side only — no NEXT_PUBLIC_ prefix)
```

`API_URL` is read at request time by `app/api/[...path]/route.ts`, so the built container image is environment-agnostic. In Podman Compose this is set to `http://backend:8080`.
